# Fun Life

실존주의 기반 자기개발 앱. 어떤 행동이든, 그 행동 **자체**가 주는 감정과 효용을 따라가면 결국 **재미**에 닿는다는 것을 스스로 그려보게 한다.

## 핵심 규칙

1. 카드는 **행동 하나**마다 만든다.
2. 새 카드에는 **행동 박스**와 **재미 박스**만 있다.
3. 유저는 그 행동이 주는 **감정 / 효용 박스**를 만들고, 행동 → … → 재미로 이어지게 연결한다.
4. **돈은 특별하게 다룬다.** 행동 카드에서 돈 관련 박스를 만들면 그 박스는 **돈 박스**(도착점)가 되고,
   돈이 어떻게 재미로 이어지는지는 행동 카드와 같은 계층의 **돈 카드**(유저당 하나)에서 따로 그린다.

### 연결 규칙 (`src/domain/graph.ts`)

| 규칙 | 이유 |
| --- | --- |
| 행동 → 재미 직결 금지 | "그냥 재밌어"가 아니라 그 사이의 감정/효용을 찾게 하는 게 핵심 |
| 행동으로 들어오는 선, 재미에서 나가는 선 금지 | 방향은 항상 행동 → 재미 |
| 돈 박스에서 나가는 선 금지 | 돈 너머는 돈 카드가 담당 |
| 중복·순환 금지 | 그래프를 읽기 쉽게 유지 |
| 행동에서 재미까지 경로가 생기면 **완성** | 경로 위의 박스·선이 하이라이트됨 |
| 돈 박스까지 이어지고 돈 카드가 완성돼 있으면 **돈 카드를 거쳐 완성** | 돈 카드가 미완성이면 "돈 카드를 이어주세요" 상태 |

### 돈 박스 / 돈 카드 (`src/domain/money.ts`)

- 행동 카드에서 박스를 만들거나 수정할 때 돈 관련 단어가 있으면 돈 박스로 바뀐다 (막지 않음).
- 띄어쓰기·대소문자를 무시하고 부분 일치로 판별한다 (`연 봉` → `연봉`). `돈독`, `돈가스`처럼 잘못 걸리는 단어는 예외 처리.
- 첫 돈 박스가 생길 때 돈 카드가 자동으로 만들어진다. 돈 카드는 목록 맨 앞에 있고 삭제할 수 없다.
- 돈 카드 안에서는 판별하지 않는다 (돈 → 경제적 여유 → … 처럼 자유롭게 쓸 수 있음).

## 인트로 (선언문)

첫 접속 시 전체 화면으로 앱의 철학을 보여준다. 카뮈의 인용, 3단계 서사(쓸모의 해체 · 재미의 복원 · 돈의 독립),
기존 도식(행동 → 노동 → 돈/성공 → 유예된 행복)과 우리의 도식(행동 → 재미, 돈 → 재미)의 대비.
`[ 내 행동의 의미를 직접 선언하기 ]`를 누르면 페이드아웃되고, 다시 보지 않는다 (`localStorage`).
오른쪽 위 `? 기획의도` 버튼으로 언제든 다시 연다. Esc로도 닫힌다.

## 재미 도식과 AI 성찰 (`#/schema`)

이 앱은 재미 자체가 아니라 **실존주의적 삶의 태도를 완성해 가기 위한 수단**이다.
카드가 모이면 그 사람만의 재미 도식이 되고, 이것을 AI에게 건네 스스로를 돌아본다.

- **데이터 내려받기 (JSON)**: 카드마다 출발점 → … → 재미/돈 경로, 잇지 못한 박스, 요약(여러 행동에 반복되는 박스 등)
- **AI 성찰 프롬프트 복사**: 도식을 읽기 쉬운 텍스트로 넣고, 자유와 선택 · 결과가 아닌 과정 · 돈의 자리 ·
  반복되는 가치 · 비어 있는 곳의 관점에서 돌아봐 달라고 요청한다. 진단·자기계발 팁으로 흐르지 않게 제약을 둔다.
- 앱이 AI를 직접 호출하지 않는다. 유저가 원하는 AI에 직접 붙여넣는다 (데이터는 기기 밖으로 나가지 않음).

## 배포 (GitHub Pages)

`main`에 push하면 `.github/workflows/deploy.yml`이 테스트 → 빌드 → Pages 배포를 한다.
처음 한 번: 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 설정.

## 로그인 붙이기 (나중에)

1. Supabase 프로젝트 생성 → `supabase/schema.sql` 실행
2. `@supabase/supabase-js` 설치, `SupabaseCardRepository implements CardRepository` 작성
   (`graph` 컬럼에 `{ nodes, edges }` 저장)
3. `src/storage/index.ts`에서 세션 유무에 따라 Local / Supabase 구현을 고르기
4. 첫 로그인 시 localStorage 카드를 Supabase로 옮기기
5. anon key는 공개돼도 되는 키라 Pages에 넣어도 됨 (보안은 RLS가 담당)
